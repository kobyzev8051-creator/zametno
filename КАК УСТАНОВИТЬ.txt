ЗАМЕТНО — заметки и дела
========================

Простые заметки с отметкой о выполнении, поиском, корзиной
и экспортом в PDF и Excel. Работает без интернета.
Заметки хранятся только на вашем устройстве.

Подробная инструкция — в файле «Инструкция пользователя.pdf»
и в самом приложении: кнопка «?» вверху или ссылка «Справка» внизу.


УСТАНОВКА
---------
Откройте ссылку на приложение в браузере, затем:

• Android (Chrome):
  кнопка «Установить» в приложении или меню ⋮ → «Установить приложение».

• iPhone / iPad (Safari):
  кнопка «Поделиться» □↑ → «На экран "Домой"» → «Добавить».

• Windows / macOS / Linux (Chrome или Edge):
  кнопка «Установить» в приложении или значок ⊕ справа в адресной строке.

После установки значок «Заметно» появится на домашнем экране
или рабочем столе, приложение откроется в отдельном окне.


ВАЖНО
-----
• Заметки не синхронизируются между устройствами: у каждого
  устройства и у каждого человека — свои.
• Чтобы сохранить копию заметок: ⬇ → «Резервная копия (.json)»
  или «Таблица Excel (.xlsx)».
• Если удалить приложение или очистить данные браузера,
  заметки удалятся. Время от времени делайте резервную копию.


ДЛЯ ТОГО, КТО ВЫКЛАДЫВАЕТ ПРИЛОЖЕНИЕ
------------------------------------
Установка работает только по защищённой ссылке (https://).
Выложите содержимое архива «Заметно.zip» на любой бесплатный
хостинг статических сайтов, например:

• GitHub Pages — github.com → новый репозиторий → загрузить файлы →
  Settings → Pages → Deploy from a branch.
• Netlify — app.netlify.com/drop → перетащить папку с файлами.
• Cloudflare Pages — dash.cloudflare.com → Workers & Pages →
  Create → Pages → Upload assets.

Получится ссылка вида https://….github.io/zametno/ — её и отправляйте.

Обновление: замените файлы на хостинге и увеличьте номер версии
в sw.js (строка const CACHE = 'zametno-v2' → 'zametno-v3').
