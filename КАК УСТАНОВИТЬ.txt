ЗАМЕТНО — заметки и дела
========================

АДРЕС ПРИЛОЖЕНИЯ:
https://kobyzev8051-creator.github.io/zametno/

Простые заметки с отметкой о выполнении, поиском, корзиной
и экспортом в PDF и Excel. Работает без интернета.
Заметки хранятся только на вашем устройстве.

Подробная инструкция — в файле «Инструкция пользователя.pdf»
и в самом приложении: кнопка «?» вверху или ссылка «Справка» внизу.


УСТАНОВКА
---------
Откройте адрес приложения в браузере, затем:

• Android (Chrome):
  кнопка «Установить» в приложении или меню ⋮ → «Установить приложение».

• iPhone / iPad (Safari):
  кнопка «Поделиться» □↑ → «На экран "Домой"» → «Добавить».

• Windows / macOS / Linux (Chrome или Edge):
  кнопка «Установить» в приложении или значок ⊕ справа в адресной строке.

После установки значок «Заметно» появится на домашнем экране
или рабочем столе, приложение откроется в отдельном окне.
Пользоваться можно и без установки — прямо в браузере.


ANDROID — УСТАНОВКА ИЗ ФАЙЛА APK
--------------------------------
Скачать последнюю версию:
https://github.com/kobyzev8051-creator/zametno/releases/latest/download/Zametno.apk
(или получите файл «Заметно.apk» от знакомых — тогда интернет не нужен)

1. Откройте файл APK (из «Загрузок» или из сообщения).
2. Если телефон попросит — разрешите установку из этого источника:
   «Настройки» → «Разрешить из этого источника», затем назад.
3. Нажмите «Установить», затем «Открыть».

Обновление: откройте новый файл APK → «Обновить», заметки сохранятся.
В версии из APK экспорт открывается через меню «Поделиться»,
а PDF — через системную печать («Сохранить как PDF»).
Заметки версии из APK и веб-версии хранятся отдельно.


ВАЖНО
-----
• Заметки не синхронизируются между устройствами: у каждого
  устройства и у каждого человека — свои.
• Чтобы сохранить копию заметок: ⬇ → «Резервная копия (.json)».
• Чтобы вернуть заметки из копии или перенести их на другое
  устройство: ⬇ → «Импорт из резервной копии (.json)» → выберите
  файл → «Добавить к моим заметкам» или «Заменить мои заметки»
  (при замене прежние заметки перейдут в корзину).
• Если удалить приложение или очистить данные браузера,
  заметки удалятся. Время от времени делайте резервную копию.


ДЛЯ АВТОРА
----------
Приложение размещено на GitHub Pages:
https://github.com/kobyzev8051-creator/zametno
Обновление: изменить файлы, увеличить номер версии в sw.js
(const CACHE = 'zametno-v8' → 'zametno-v9')
и отправить на GitHub — установленные приложения обновятся сами.
APK для Android собирается и проверяется на GitHub автоматически при
каждой отправке; при успешной проверке файл по ссылке выше обновляется
сам. Ключ подписи и пароль — в папке
android-signing: храните её — без неё обновление APK не установится
поверх прежней версии. Никому не передавайте и не публикуйте.
