# Заметно — заметки и дела

<img src="app/icons/icon.svg" width="72" alt="Значок приложения «Заметно»">

Простое приложение для заметок: отметка о выполнении, поиск, корзина с восстановлением,
экспорт в PDF и Excel, резервная копия с импортом. Устанавливается на телефон, планшет и компьютер, работает без интернета.
Заметки хранятся только на устройстве пользователя.

**Открыть приложение:** https://kobyzev8051-creator.github.io/zametno/

**Android (файл APK):** https://github.com/kobyzev8051-creator/zametno/releases/latest/download/Zametno.apk

**Windows 10 / 11 (установщик):** https://github.com/kobyzev8051-creator/zametno/releases/latest/download/Zametno-Setup.exe

## Установка

- **Android (Chrome):** кнопка «Установить» в приложении или меню ⋮ → «Установить приложение».
- **iPhone / iPad (Safari):** «Поделиться» □↑ → «На экран "Домой"» → «Добавить».
- **Компьютер (Chrome, Edge):** кнопка «Установить» в приложении или значок ⊕ в адресной строке.

Подробнее — [Инструкция пользователя](https://kobyzev8051-creator.github.io/zametno/help.html).

## Что где лежит

| Папка | Что внутри |
|---|---|
| [`app/`](app) | Само приложение — оно же сайт: `index.html` (приложение), `help.html` (справка), `sw.js` (работа без интернета), `manifest.webmanifest` и `icons/` (установка и значки) |
| [`android/`](android) | Оболочка для Android (Capacitor): настройки, значки и заставки, модуль печати |
| [`windows/`](windows) | Программа для Windows (Tauri): исходники на Rust, настройки установщика, автоматическая проверка |
| [`tools/`](tools) | `serve.ps1` — локальный сервер для проверки приложения на компьютере |
| [`.github/workflows/`](.github/workflows) | Автоматические сборки: сайт, APK для Android, установщик для Windows |

Сайт публикуется из папки `app` автоматически. APK и установщик собираются и проверяются на серверах GitHub
при каждом изменении и выкладываются по постоянным ссылкам выше.
